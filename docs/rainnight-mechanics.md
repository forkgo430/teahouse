# 雨夜模式 · 机制方案

> 状态：**方案定稿 + 机制层已实现，内容数据为占位骨架**（`data/mode-rain.js`）。
> 涉及成人内容的具体文本不在引擎侧编写，由用户提供或经模型生成。

## 1. 定位

雨夜模式是茶馆的**内置模式包**：同一引擎内核，换一套数据、规则开关和 UI 主题。

| 维度 | 茶馆标准 | 雨夜模式 |
|---|---|---|
| 主题 | 白玻璃拟态（清透） | 靛蓝暗调（`mode-rainnight`），红色警示点缀 |
| 雨势 | 0.32 起随进度升至 0.75 | 固定 0.85 起，压着剧情走 |
| 边界系统 | 可选启用 | **强制启用**（guard 硬开关） |
| 当轮意愿卡 | 不显示 | 主界面常驻（雨夜专属 UI） |
| 内容 | 中性示例 | 《雨夜求助》骨架（占位） |

## 2. 核心循环

```
求助出现 → 倾听 / 追问（信息获取）
   → 权衡（自身压力 / 疲惫 vs 求助者信任 / 安全感）
   → 帮（如何帮）或不帮（如何不帮）
   → 每一步推进都需确认边界 → 下一夜
```

一次完整循环 4–8 轮，跨 2–3 夜。

## 3. 独特机制

### 3.1 同意与边界（已实现：`src/boundary.js`）

- **同意公式**：成年 ∧ 清醒 ∧ 自愿 ∧ 可撤回 ∧ 可重新协商 ∧ **当轮公开表达**
- **非同意来源**（发生 ≠ 同意）：经济帮助 / 住宿 / 债务援助 / 隐藏打算 /
  内心想法 / 身体状态描写 / 路线未开启 / 单方面推定 / 沉默 / 未回应
- **当轮有效**：上一轮的「接受」这一轮作废，必须重新确认（`consent.turn` 校验）
- **撤回**：立即停、不追问；路线冻结不注销；尊重撤回信任 +5，纠缠 −15
- **冷静期**：拒绝后 3 轮内同方向再试探 = 纠缠，信任递减
- **重新协商**：解冻路线，条款写入当轮意愿，下轮重申

引擎接入方式：分支写 `requiresConsent: '角色id'`，guard 在写入前拦截，
条件不满足整轮拒绝且状态零变化。

### 3.2 债务与线索（已实现：clues + 世界书分类）

- 线索分三类展示：概要 / 主线 / 任务（书架·世界书页签）
- 「债务线索」= 帮助行为落账（ledger.expense）并生成一条线索：
  谁帮了、帮了多少、求助者的态度如何变化 —— 帮助不买来同意，只累积债务叙事

### 3.3 秘密与揭露（机制位已留，数据待填）

- 每个角色一组 `flags.secret_*`，揭露条件用标准条件表达式（如三段线索集齐）
- 揭露动作 = 一个 `unlock.clue` 事件效果，走现有 unlock 管线

### 3.4 NPC 自主行动（机制位已留，调度待接）

- NPC 在不被玩家推进时也会行动：实现为**定时事件**（`when` + `require` 已支持），
  只差一份「自主行动表」数据 —— 用户文档提供后填入

## 4. 数值体系（占位，形状已建）

| 角色 | 数值 |
|---|---|
| 求助者 | 信任 / 安全感 / 未来焦虑 |
| 你 | 压力 / 疲惫 / 自尊 |

全部走 clamp + 留痕管线；越界自动夹紧并在数值面板标注。

## 5. 结局矩阵（占位形状）

| 结局 | 触发（示意） |
|---|---|
| 接住了 | `flags.took_case` |
| 这次没有 | `flags.declined` |
| 中途散场（待补） | 压力/疲惫双顶 + 主动退出 |
| 越界的代价（待补） | 边界被反复突破（freezeEffects 路线） |

## 6. UI 专属（已实现）

- `mode-rainnight` 主题变量（靛蓝暗调）
- 当轮意愿与边界卡（`.consent-card`，随角色状态实时染色）
- 模式徽章（顶栏）与启动页模式行
- 雨势 0.85 + 闪电概率提升位
